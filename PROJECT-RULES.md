# Project Rules

1. Brand spelling is exactly **Hussien Badr English**.
2. Preserve the supplied `assets/brand-logo.png` and `assets/founder-portrait.png`; do not redraw, retouch, recolour, or replace them without approval.
3. Keep GitHub Pages-compatible relative paths.
4. Keep lesson, FAQ, quiz and site data separate from presentation.
5. Never expose API keys, passwords or private credentials in public files.
6. Work in a review branch before production updates; preserve releases and changelog.
7. Run `node --check` on JavaScript and the validation script before releasing.
8. Do not claim a feature is implemented until it is present and tested.
9. Placement results are indicative only until externally validated and calibrated.
10. The official founder biography must be based only on information approved by the founder.
