# Hussien Badr English Academy — Static Edition 1.0.0

منصة تعليمية عربية/إنجليزية بهوية حسين بدر، مهيأة للنشر على GitHub Pages دون خادم أو اشتراك استضافة.

## محتويات الإصدار
- صفحة رئيسية تعريفية وصفحة عن الأكاديمية والمؤسس.
- المسارات المستهدفة A1 وA2 وB1 وB2 وC1.
- مكتبة من 25 درساً تعليمياً أصلياً (5 لكل مستوى) مع أهداف وشرح وأمثلة وتدريب.
- اختبار تشخيصي من 30 سؤالاً مع تصحيح ونتيجة استرشادية.
- مركز أسئلة شائعة من 30 سؤالاً مع البحث والتصنيف.
- صفحات الموارد والتواصل والخصوصية والشروط، ولوحة تقدم محلية قابلة للتصدير.
- شعار المستخدم وصورة المؤسس المرفقة/المحفوظة سابقاً.
- ملفات بيانات JSON منفصلة عن التصميم لتسهيل التوسع.

## النشر من هاتف Android أو الكمبيوتر
1. نزّل ZIP واستخرج محتوياته.
2. أنشئ مستودعاً عاماً جديداً باسم `hussien-badr-english-academy` في حساب GitHub.
3. ارفع **محتويات المجلد** إلى جذر المستودع، ولا ترفع ملف ZIP وحده.
4. تأكد أن `index.html` موجود في الجذر مباشرة، وأن مجلدات `assets` و`css` و`js` و`data` موجودة بجانبه.
5. من Settings → Pages اختر Deploy from a branch، ثم `main` و`/(root)`، واحفظ.
6. انتظر نجاح GitHub Actions / Pages، ثم اختبر الموقع على الهاتف والكمبيوتر.
7. عنوان الموقع المتوقع: `https://gnathussinbder-star.github.io/hussien-badr-english-academy/`، بشرط إنشاء المستودع بهذا الاسم والمالك المذكور.

## تعديل المحتوى لاحقاً
- الأسئلة الشائعة: `data/faq.ar.json`.
- الدروس: `data/lessons.json`.
- أسئلة اختبار تحديد المستوى: `data/placement-questions.json`.
- بيانات الأكاديمية وروابطها: `data/site-config.json` و`js/site.js`.
- التصميم العام: `css/site.css`.

## تنبيه حول النطاق
هذا الإصدار Static. لا يحتوي تسجيل حسابات أو قاعدة بيانات سحابية أو لوحة إدارة محمية أو مزامنة بين الأجهزة أو تقييم ذكاء اصطناعي. تقدم الطالب المحلي لا ينتقل تلقائياً إلى جهاز آخر. يمكن إضافة هذه الخدمات مستقبلاً باستخدام خادم وقاعدة بيانات مناسبة.

## حدود المحتوى والتقييم
الـ25 درساً هي محتوى تأسيسي أصلي منشور في هذه الحزمة وليست مكتبة كاملة من مئات الدروس. اختبار تحديد المستوى من 30 سؤالاً تدريبي واستدلالي وليس اختبار CEFR معيارياً أو شهادة دولية. يلزم توسيع بنك الأسئلة، ومراجعة خبراء، وتجريب ومعايرة قبل استخدام النتائج في قرارات رسمية.
